# Agent Note: 天枢列的标识改为纯文字

Status: implemented

[English](2026-08-26-tianshu-sidebar-text-identity.md) | 中文

## Problem

品牌列有两处沿自参考设计稿（design 首页）的标识元素，均于 2026-08-26 被产品所有者提出修改。

其一，新建会话渲染为浅色浮起药丸——在其下导航块（配置管理 / 定时任务 / 会话管理）之上自成一个视觉层级，所有者不想要这个层级：四行应读作一个对齐的列表。

其二，列内承载一个几何徽标（`TianshuMarks.tsx` 中的内联 SVG 球体，为参考 logo 的手绘近似，包 README 亦如实记录）。所有者要求删除，并让平台名「天枢平台」独立承担标识，选一款适合政务平台、同时保有科技感的字体。

## Decision

新建会话改为导航列表的首行样式：与 `.navItem` 相同的几何（38px 高、10px 圆角、12px 水平内边距、10px 图标-文字间距）、相同 ink（`label-secondary`，悬停转 primary）、相同悬停填充（`--dsw-specific-sidebar-nav-item-hover`），展开列与收起轨道两态一致。图标采用与导航图标相同的 16px 尺寸。

徽标彻底删除：`TianshuEmblem`、收起态切换按钮上的轨道席位、样式表中徽标与面板图标的悬停交换逻辑一并移除。收起态切换按钮现在始终显示面板图标，与上游 dsh 轨道一致。

字标以纯文字渲染，使用恰好覆盖「天枢平台TIANSHUPLATFORM」的内联 woff2——思源宋体 CN Heavy 的子集（SIL OFL 1.1；子集化与内嵌均为许可证允许），以 data URI 形式置于新建的 `TianshuMarks.module.css`，共 5.5KB。字标为产品所有者从六方案评审加两轮细化中选定的 G2 变体：中文主标 21px / 0.18em 字距，下方大写拉丁副标 `TIANSHU PLATFORM` 8px / 0.34em 字距，被一条全行延伸线贯穿。1px 线走副标视觉中线，从行首穿过字形、延伸到折叠按钮下方，渐隐（40%→4% 白）；外壳 `.logoRow` 的裁剪是线的终点（`.brand` 不再裁剪，否则线会止步于字标盒子）。副标以背景蓝 `paint-order: stroke` 光晕（列渐变顶色 `#2563EB`）遮线：字形周围击穿线条、字隙透线，仪表铭牌效果。宋体笔锋承载公文语系，宽字距拉丁副标承载机构双语身份。字体声明 weight 700，使 woff2 加载期间或加载失败时系统回退栈（`STSong` / `SimSun` / `Helvetica Neue`）保持合理观感。

本包没有资源管线（tsdown/rolldown 不处理文件资源——这正是徽标当初以内联 SVG 实现的原因），因此 data URI 不是权宜之计，而是同一无构建依赖路线的沿用，先例为 ui-conversation 的 `DshChipCell`。

## Consequences

列读作一个列表：四行、一种节奏，主操作不再自成一档。这是产品所有者对参考设计稿的有意偏离——design 首页的药丸不再是该元素的实现目标。

删除徽标移除了轨道上唯一的品牌存在：收起后列内显示通用的面板切换图标。所有者接受；字标无法塞进 56px 轨道。

扩展字标文字从此意味着重新生成字体子集（`pyftsubset --text=… --flavor=woff2 --desubroutinize`）；其余码点回落系统字体栈。README 的 Known Limitations 在原「手绘徽标」条目位置记录了这条维护事实。

子集嵌入后经字节级校验与生成的 woff2 完全一致（手工粘贴曾丢失一个 base64 字符，校验捕获）。重新生成时应保留该校验步骤。

## Alternatives considered

**保留药丸并调轻样式。** 可保留参考设计稿绘制的主操作层级。否决：所有者明确要求行对齐，且导航行样式不损失任何功能——按钮仍在列表首位，保留 tooltip 与 aria-label。

**发布完整 OTF 由浏览器加载。** 四个字形付出 8.8MB，且打包器不支持资源路径。子集仅 1.3KB 且无需管线。

**仅用系统字体栈的粗字重。** 部署目标平台上没有任何系统字体统一具备 Heavy 字重（PingFang 最高 Semibold，YaHei 最高 Bold），标识将因机器而异。内联子集在任何机器上钉住字形。

**手绘字形标识（逐字 SVG 路径）。** 在固定尺寸下与字体逐像素同观，但路径数据需手工维护，无工具能从文本再生成。子集可由任意思源黑体发行版再生成。

## Testing

包内套件通过（37 项测试）：字标仍以可访问名称构成第二个 New Session 按钮，轨道切换按钮保留打开/收起标签，无测试引用徽标 SVG。仓库 `typecheck` 干净。内嵌 base64 经程序化校验与子集字节完全一致。
