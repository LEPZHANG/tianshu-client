# Agent Note: 天枢品牌列的标识改为纯文字

Status: implemented

[English](2026-08-26-tianshu-sidebar-text-identity.md) | 中文

## 问题

品牌列有两处标识元素沿自参考设计稿（design 首页），均于 2026-08-26 被产品所有者提出质疑。

其一，新建会话渲染为浅色浮起胶囊——在其下方的导航块（配置管理 / 定时任务 / 会话管理）之上自成一个视觉层级，而所有者要去掉这个层级：四行应当读作一个对齐的列表。

其二，列内承载一个几何徽标（`TianshuMarks.tsx` 中的内联 SVG 球体，画来近似参考 logo，包 README 中也如实承认它只是手绘替代品）。所有者要求删除它，改由平台名「天枢平台」独立承担标识，并选一款适合政务平台、同时仍要有科技感的字体。

## 决策

新建会话现在按导航列表首行的样式呈现：与 `.navItem` 相同的几何（38px 高、10px 圆角、12px 水平内边距、10px 图标与文字间距）、相同的 ink（`label-secondary`，悬停转 primary）、相同的悬停填充（`--dsw-specific-sidebar-nav-item-hover`），展开列与收起轨道两态一致。图标采用与导航图标相同的 16px 尺寸。

徽标被彻底删除：`TianshuEmblem`、它在收起态切换按钮上的轨道席位，以及样式表中徽标与面板图标的悬停交换，全部移除。收起态切换按钮现在始终显示面板图标，与随发行版交付的 dsh 轨道一致。

字标以纯文字渲染，使用恰好覆盖「天枢平台TIANSHUPLATFORM」的内联 woff2——思源宋体（Source Han Serif）CN Heavy 的一个子集（SIL OFL 1.1；子集化与内嵌均为许可证允许），以 data URI 形式置于新建的 `TianshuMarks.module.css`，共 5.5KB。这套字标是产品所有者从六个变体的评审加两轮细化中选定的 G2 变体：中文名 21px / 0.18em 字距，下方是小号大写拉丁副标 `TIANSHU PLATFORM`，8px / 0.34em 字距，被一条贯穿整行的发丝线横贯。这条 1px 线走在副标的视觉中线上，从行首穿过字形、一直延伸到列折叠按钮下方，并从 40% 白渐隐到 4%；外壳 `.logoRow` 的裁剪才是这条线的终点（`.brand` 不再裁剪，否则线会止步于字标盒子）。副标通过一圈背景蓝的 `paint-order: stroke` 光晕（列顶部渐变色标 `#2563EB`）遮住线条：字形周围把线击穿，字隙则让线透出来——仪表铭牌的观感。宋体的笔形承载公文语体，宽字距的拉丁副标承载机构双语身份。字体声明 weight 700，使 woff2 加载期间、或万一加载失败时，系统回退栈（`STSong` / `SimSun` / `Helvetica Neue`）仍保持合理观感。

本包没有资源管线（tsdown／rolldown 不处理任何文件资源——这正是徽标当初做成内联 SVG 的原因），因此 data URI 不是权宜之计，而是同一条免构建路线的沿用，先例是 ui-conversation 的 `DshChipCell`。

## 后果

这一列读作一个列表：四行、一种节奏，主操作不再自成一档。这是产品所有者对参考设计稿的有意偏离——design 首页的胶囊不再是这个元素的目标。

删除徽标也移除了轨道上唯一的品牌存在：收起后，列内显示的是一个通用的面板切换按钮。所有者接受这一点；字标塞不进 56px 的轨道。

此后扩展字标文字就意味着重新生成字体子集（`pyftsubset --text=… --flavor=woff2 --desubroutinize`）；其余码点一律回落到系统字体栈。README 的 Known Limitations 在原先「手绘徽标」那条的位置记录了这条维护事实。

子集内嵌之后，经字节级校验与生成的 woff2 完全一致（一次手工粘贴曾漏掉一个 base64 字符，正是这项检查发现的）。重新生成时应保留这一步校验。

## 曾考虑的替代方案

**保留胶囊，只把样式调轻。** 这样能保住参考设计稿画出的主操作层级。不采用：所有者明确要求各行对齐，而导航行的样式不损失任何功能——按钮仍然领头，并保留它的 tooltip 与 aria-label。

**直接发布完整 OTF，交给浏览器加载。** 四个字形要付出 8.8MB，还要多一条打包器并不支持的资源路径。子集只有 1.3KB，且不需要任何管线。

**只用系统字体栈的 Heavy 字重。** 部署涉及的各平台上，没有任何随系统交付的字体统一具备 Heavy 字重（PingFang 最高到 Semibold，YaHei 最高到 Bold），标识会因机器而异。内联子集把字形钉在了所有机器上。

**手绘字形标识（逐字的 SVG 路径）。** 在固定尺寸下与字体逐字节同观，但路径数据需要手工维护，没有工具能从文本再生成。子集则可以从任意思源黑体发行版再生成。

## 测试

包内套件通过（37 项测试）：字标按可访问名称仍然是第二个 New Session 按钮，轨道切换按钮保留它的展开／收起标签，且没有任何测试引用过徽标的 SVG。仓库 `typecheck` 干净。内嵌的 base64 经程序化校验，确认解码结果与子集字节完全一致。
